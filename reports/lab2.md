# OS Lab2 Report

## 功能总结

我重写了 `sys_get_time` 和 `sys_trace` 两个系统调用，使其在开启 Sv39 分页模式之后能够正常工作。其中，`sys_get_time` 使用 `translated_byte_buffer` 来读取 `TimeVal` 结构体，从而避免了结构体跨页的问题；`sys_trace` 手动翻译用户传入的虚拟地址，并检验其合法性。

我添加了 `sys_mmap` 和 `sys_munmap` 两个系统调用。具体的实现方法为，在 `TaskManager` 中增加接口，为当前处于 Running 状态的任务分配和回收虚拟空间。这些接口会调用 `MemorySet` 中的接口 `mm_map` 和 `mm_unmap` 来修改页表。`mm_map` 的实现较为简单，相当于在原有的 `insert_framed_area` 方法中加入一些校验；`mm_unmap` 的实现较为复杂，需要考虑用户传入任何地址的情况，并分类讨论 `MapArea` 拆分的逻辑。
